# PSA 프로토타입 — 프로젝트 손익을 실시간으로 보는 사내 PSA 레이어

프로젝트 기반 서비스 사업의 **수주금액과 투입 인건원가를 이어 마진을 실시간으로 계산**하고,
저마진·과부하·적자 위험을 신호등으로 먼저 보여주는 사내 PSA(Professional Services Automation) 도구의 UI 프로토타입입니다.

> 🔗 **라이브 데모**: https://mzd-nrkim.github.io/psa-prototype/
> (목업 데이터 기반, 로그인 없이 바로 클릭해볼 수 있습니다)

---

## 왜 만드나 — 풀려는 문제

프로젝트 손익은 계약 파일·견적표·투입 인력표·비용표·주간보고에 **흩어져** 있어
"이 프로젝트가 지금 정상인가"를 즉시 알 수 없습니다. 엑셀 관리의 한계는 분명합니다:

- 중복입력·계산 실수·권한통제 부재
- 무엇보다 **손실이 확정되고 나서야** 원인을 복기하게 되는 뒤늦음

이 도구는 손익을 **DB의 확정 수식**으로 계산하고(AI 추정이 아님), 위험을 사전에 신호로 띄웁니다.

---

## 핵심 화면 (3개)

| 화면 | 경로 | 무엇을 하나 |
|------|------|-------------|
| **포트폴리오 대시보드** | `/` | 전사 마진율·위험 프로젝트 수·가동률을 요약하고, 프로젝트를 마진율 순으로 나열해 **위험한 것을 목록 맨 위로** 올린다 |
| **프로젝트 손익 상세** | `/project/{코드}` | 수주금액 − Σ(배정별 인건원가) = 마진을 배정 단위까지 드릴다운. **M/M을 조정하면 마진율이 실시간 재계산** |
| **임직원 투입 현황** | `/people` | 한 인력이 여러 프로젝트에 중복 투입돼 **가동률이 과부하인지**, 벤치(미배정)가 누구인지 |

### 신호등 규칙 (health)

프로젝트·전사 마진율을 3단계 색으로 고정 의미화합니다:

- 🟢 **정상(ok)** — 마진율 30% 이상
- 🟡 **주의(watch)** — 15% 이상
- 🔴 **위험(risk)** — 15% 미만 (저마진 / 일정 지연 / 적자 사유가 함께 표기)

## 데이터 모델 개념 (기획 관점)

```
계약(수주금액)  ─┐
                 ├─▶  프로젝트  ──▶  배정(누가·언제·몇 M/M·어느 등급)  ──▶  인건원가
등급 표준단가  ─┘                                                          │
                                                                          ▼
                                          마진 = 수주금액 − Σ 인건원가,  마진율 = 마진 / 수주금액
```

- **인건원가** = 투입 시점 등급의 표준단가 × 투입 M/M (시점 단가 기준)
- **매출**은 계약(수주)에서 프로젝트로 배분된 값
- 인당 수익·급여파생 원가 등 **민감 지표는 권한에 따라 값이 통제**됨

자세한 데모 흐름은 [`docs/데모-시나리오.md`](docs/데모-시나리오.md)를, 제품 가치·FAQ는 [`docs/2026-07-06_PSA-PRFAQ.md`](docs/2026-07-06_PSA-PRFAQ.md)를 참고하세요.

## 현재 범위 & 상태

- **UI 프로토타입 단계** — 화면·상호작용·계산 로직은 동작하되, 데이터는 **인메모리 목업**입니다.
- 손익·포트폴리오 롤업·M/M 시뮬레이션 계산은 **단위 테스트로 검증**된 순수 로직입니다.
- **후속 계획**: 실데이터 연동(원가·매출 소스), 수동입력 기반 사내 MVP → 자동 연동.

> ⚠️ 화면의 회사명·인물·수치는 모두 **가공 예시**입니다. 실제 고객·직원 데이터가 아닙니다.

## 기술 스택 & 로컬 실행

SvelteKit(정적 배포) + TypeScript. 디자인 토큰 계약은 [`DESIGN.md`](DESIGN.md) 참조.

```bash
npm install
npm run dev      # 로컬 개발 서버
npm run test     # 단위 테스트(vitest)
npm run build    # 정적 빌드 (GitHub Pages 배포 산출물)
```
