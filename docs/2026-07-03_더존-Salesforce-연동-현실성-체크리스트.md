# 사내 PSA(가칭) — 더존 / Salesforce 연동 현실성 체크리스트

> 작성 2026-07-03 · 업데이트 2026-07-06 · 목적: 이 프로젝트의 성패는 "데이터가 자동으로 흘러오느냐"에 달려 있다. 그런데 작성자(사원)는 더존 세부를 모른다. 그래서 이 문서는 **전제가 아니라 "누구에게 무엇을 물어야 하는지" 질문 목록**이다.
> ⚠️ 아래 어느 항목도 "된다/안 된다"로 단정하지 않았다. 전부 확인 대상이다.

**2026-07-06 현황 업데이트**
- **수동입력 MVP 방향 확정**: 더존·SF 자동 연동은 당장 고려하지 않는다. D-Fallback의 "수동입력 MVP"가 1단계 기본 노선.
- **Jira 연동 가능 확인**: Jira API 테스트 가능. 이슈·태스크 연동을 설계에 반영할 수 있음.
- **그룹웨어/결재 연동 배제**: 아이디어 수준이며 더존 시스템 권한 미파악 → 당장 범위 외.

---

## 왜 이게 제일 중요한가

"연결해주는 웹페이지"에서 **연결이 안 되면** = 사람이 더존·SF·엑셀 보고 이 툴에 재입력 = **또 다른 엑셀**이 된다. 자동 피드가 되면 진짜 가치가 생기고, 안 되면 "수동입력 MVP"로 스코프를 낮춰야 한다. 그 갈림을 정하는 게 이 체크리스트다.

## A. 더존 (급여·등급·인건비 = 원가 입력)

**누구에게?** 경영지원/인사팀 + 더존 도입 담당자(정보시스템 담당).

- [ ] 우리가 쓰는 더존 제품이 정확히 무엇인가? (iCUBE / Bizbox / OmniEsol / Smart A 등)
- [ ] 그 제품에 **"프로젝트별 손익 분석"** 기능이 이미 있나? 있으면 우리가 그걸 쓰고 있나/쓸 수 있나? *(있으면 우리가 만들 범위가 줄거나, 반대로 "그거 더존에 있잖아"에 답해야 함)*
- [ ] 급여·인건비·등급 데이터를 **API로** 뽑을 수 있나? 아니면 **정기 Excel/CSV export**만 되나?
- [ ] 우리(개발/실무)가 그 데이터에 **접근할 권한**이 있나? 승인 절차는?
- [ ] 우리가 필요한 건 **급여 원본**인가, **등급별 표준단가**만으로 충분한가? *(후자면 민감도가 크게 낮아짐 — 강력 권장)*
- [ ] 근태/투입 시간 데이터도 더존에 있나? (멘먼스 실적 산정에 쓸 수 있음)

## B. Salesforce (계약·PO = 매출 입력)

**누구에게?** Salesforce/계약관리팀(계약 준비·PO 담당).

- [ ] 계약팀이 Salesforce에서 **정확히 무엇을** 관리하나? (계약, PO, 수주금액, 고객사, 기간?)
- [ ] 그 데이터를 우리 툴이 **받을 수 있나**? (API 연동 / 리포트 export / 수동 공유)
- [ ] 반대 방향 대안: **Salesforce 위에 얹는 게 나은가?** *(SF 쓰는 조직엔 Certinia 같은 SF-네이티브 PSA가 매끄럽다는 시장 신호 있음 — 우리가 자체 웹앱 대신 SF 앱으로 갈지 검토 가치)*
- [ ] 계약 ↔ 프로젝트 매핑 키가 있나? (계약 1건 = 프로젝트 1건인가, 1:N인가)

## C. 데이터 민감도 · 보안 (기록 주체가 인사·경영이므로 필수)

- [ ] 인당 수익/급여파생 원가는 사내 최고 민감 데이터 — **누가 열람 가능한지 윗선 결정 필요** (권한은 높으신 분들 몫).
- [ ] 이 툴 서버/DB는 어디에 두나? (사내 온프렘 / 사내망 전용 — 외부 SaaS 반출 금지 여부 확인)
- [ ] 급여 원본을 안 들여오고 **등급단가만** 쓰면 사고 위험이 줄어든다 — 이 방침을 채택할지 결정.
- [ ] 접근 로그·감사 추적이 필요한가? (누가 언제 누구 수익을 봤나)

## D. Fallback — 자동 연동이 안 될 경우

연동이 막히면 프로젝트를 접는 게 아니라 **스코프를 낮춘다**:

1. **수동입력 MVP** — 등급단가·계약금액을 사람이 한 번 입력, 배정·손익·주간보고는 이 툴이 계산.
   - 그래도 엑셀보다 낫다(계산 자동·권한·이력·대시보드). 단, "자동 연동"은 아님을 **명시적으로 인정**하고 보고.
2. 이후 A/B 연동이 열리면 입력을 피드로 대체.

## 요약: 지금 당장 물어야 할 3가지

1. (경영지원/정보시스템) **더존 제품명 + 프로젝트 손익 기능 유무 + 데이터 반출 방식**
2. (계약팀) **Salesforce 계약/PO 데이터를 우리가 받을 수 있나**
3. (윗선) **급여 원본 vs 등급단가 / 인당 수익 열람 범위** — 보안·권한 방침
