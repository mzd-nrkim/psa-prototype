# 사내 PSA(가칭) — 상용툴 리서치

> 작성 2026-07-03 · 목적: "우리가 만들려는 게 어떤 카테고리이고, 이미 파는 툴이 있는데 왜 사서 안 쓰고 만드나"에 답하기 위한 read-only 조사.
> 결론 요약: 이건 **PSA(Professional Services Automation)** 라는 성숙한 카테고리다. 바퀴를 다시 발명하는 것이므로, "그래도 만든다"의 근거를 명시적으로 확보해야 한다.

---

## 1. 우리가 만들려는 것의 정식 명칭: PSA

PSA는 **프로젝트 기반(용역/SI) 회사**를 위해 아래를 하나의 시스템에 묶는 소프트웨어 카테고리다:

- 영업기회 → 리소스(인력) 배정 → 프로젝트 실행 → 공수·비용 입력 → 청구/정산 → 성과 리포트
- 일반 PM 툴과 다른 점: **돈 중심**이다 — 청구가능 가동률(billable utilization), 프로젝트별 마진, 인당 기여, 전사 손익을 실시간에 가깝게 본다.

우리가 적은 요구("임직원 각각의 수익 계산 · 전사 손익계산서 · 프로젝트 진척/투입인원/규모 한눈에")가 정확히 PSA의 핵심 기능 집합이다. 시장 규모는 2024년 약 $12.4B → 2033년 $40B대로 성장 예측 — 즉 **잘 정의되고 검증된 영역**이다.

## 2. 상용툴 지형 (2026)

| 툴 | 포지션 | 가격(1인/월, 대략) | 특징 |
|---|---|---|---|
| Productive | 소규모/에이전시 | ~$10 | 저가 자가가입형 |
| Scoro | 소~중견 | ~$19.9 | **역할·서비스·프로젝트 단위 실시간 마진 추적**이 강점 (내/외부 비용 모두) |
| Rocketlane | 소~중견 | ~$19 | 온보딩·고객협업 강점 |
| BigTime | 소~중견 | ~$20 | 시간추적+청구+재무 리포트 통합 |
| Projectworks | 컨설팅 | 문의 | 마진·가동률·프로젝트 건강도 실시간 |
| BQE Core | 소~중견 | 문의 | **PSA+회계 하이브리드** (대차대조표·손익계산서 내장) |
| Kantata | 중견~대기업 | ~$45+ (비공개, 영업문의) | AI 기반 리소스 최적화·예측 |
| Certinia | 대기업·**Salesforce 종속** | ~$175+ (비공개) | Salesforce 위에 구축 — SF 쓰는 조직에 정합 |
| NetSuite OpenAir | 대기업 | 문의 | ERP 연계 |

패턴:
- **저가 자가가입 계층($10~20/인·월)** 이 존재한다 — 소규모 회사엔 이게 "그냥 사면 되는 것 아니냐"의 유력 대안.
- Salesforce를 쓰는 조직엔 **Certinia**가 가장 매끄럽다 (우리 계약팀이 Salesforce를 쓴다는 점이 여기서 의미 있음 — 뒤 리서치 필요).

## 3. 국내 상황 — 더존이 이미 일부를 한다 (반드시 확인)

- **더존 iCUBE**(중견기업 이상 ERP)는 문서상 **"프로젝트별 손익 분석"·원가관리** 기능을 이미 제공한다고 표기됨.
- 더존 **OmniEsol**은 AI 기반 차세대 ERP+그룹웨어 융합 플랫폼.
- 급여/인사/근태 올인원 솔루션도 더존 라인업에 있음.

> ⚠️ 함의: **"우리가 만들려는 프로젝트 손익 기능의 일부를 우리가 이미 라이선스한 더존이 갖고 있을 수 있다."** 이걸 확인 안 하면 보고 자리에서 "그거 더존에 있지 않아?"에 무너진다. → 연동 체크리스트 문서의 최우선 질문으로 넘긴다.

## 4. Build vs Buy 판단 프레임

"그래도 사내 구축"의 정당한 근거는 아래 중 **실제로 해당하는 것**만이다 (희망사항 말고):

| 근거 | 우리에게 해당하나? (확인 필요) |
|---|---|
| **Fit** — 우리 등급체계·멘먼스 원가산정 룰이 상용툴 표준과 안 맞음 | ? (우리 원가산정 방식 파악 필요) |
| **데이터 민감도** — 인당 수익/급여파생 원가를 외부 SaaS에 못 올림 | 유력 (사내 전용이라 통제) |
| **커스텀 연동** — 더존+Salesforce를 우리 방식으로 이어야 함 | ? (양쪽 데이터 접근성 확인 필요) |
| **비용** — 소규모라 상용 구독이 오히려 비쌈 | △ (인원수 × $20/월 vs 구축·유지비 비교 필요) |
| **이미 있는 자산 재활용** — lodestar 스택(FastAPI+SvelteKit+PG) 승계 | 유력 |

경계선: **소규모 + 표준 요구**면 Scoro/BigTime 구독이 이김. **데이터 민감 + 커스텀 연동 + 이미 우리 스택 있음**이면 구축이 이긴다. 우리 케이스는 후자 쪽 신호가 있지만, `?` 칸들을 채워야 확정된다.

## 5. 이 리서치가 남기는 후속 질문

1. 더존 어느 제품을 쓰나? iCUBE의 "프로젝트별 손익"을 우리가 쓸 수 있나/이미 쓰나?
2. Salesforce 계약팀 데이터(계약·PO)를 우리가 받을 수 있나? → Certinia 방식(SF 위 구축)이 대안이 될 수도.
3. 우리 인원 규모 × 저가 PSA 구독가 vs 구축·유지비 실제 비교치.
